# Job application drafts

## Inputs

- `data/profile.md`
- Company, role title, JD (required for quality)
- Optional: tailored resume from same session
- Optional: application form questions (paste exact prompts)

## Deliverables

### Cover letter (default: 250–400 words)

Structure:

1. Opening — role + genuine hook about company/product (specific, not generic)
2. Fit — 2 paragraphs tying profile achievements to JD requirements
3. Close — enthusiasm + availability + sign-off

Provide **full letter** and **short version** (150 words) for portals with character limits.

### Common application questions

| Question type | Approach |
|---------------|----------|
| Why this company? | 1 product/mission detail + 1 personal alignment |
| Why this role? | JD responsibilities ↔ your recent work |
| Salary expectations | Template only; user fills number; suggest researching range |
| Work authorization | User confirms facts; do not guess |
| Years of experience with X | Count only from profile dates |

### Email to recruiter (optional)

Subject line + 4–6 sentence body + attach resume reminder.

## Output template

```markdown
## Cover letter — ready to paste
[text]

## Short version (if needed)
[text]

## Application Q&A
### [question]
[answer]

## Tracker snippet
[paste-ready row for tracker.md]
```

## After drafting

Append or show row for `data/tracker.md`:

`| Date | Company | Role | Status | Link | Notes |`

Status values: `Shortlist`, `Applied`, `Screen`, `Interview`, `Offer`, `Rejected`, `Withdrawn`.

## Rules

- Never submit forms or send email on the user's behalf.
- Flag if JD asks for information not in profile.md.
- Avoid repeating the resume verbatim; add narrative and motivation.
